# 输出格式规范

---

## 回答结构

```markdown
## 标题

根据检索结果 [1][2]，AI能力中心包括...

### 参考资料

**📄 知识库来源**

[1] [智慧树AI教学中心产品手册](https://kb.zhihuishu.com/doc/12345) - 产品手册_v1.0.pdf

**🌐 互联网来源**

[2] [2026年AI教育行业趋势报告](https://example.com/report) - 📅 2026-03-21 - 腾讯新闻
```

---

## 核心规则

1. **正文引用** — `[1][2]` 紧跟文字，不堆末尾
2. **图文交叉** — 图片穿插正文中相关位置
3. **来源分组** — 📄 知识库 / 🌐 互联网 分开列出
4. **可点击链接** — 参考资料必须使用 Markdown 链接格式 `[标题](URL)`，确保可直接点击

---

## 引用格式

### 知识库来源 (search)
```
[序号] [{title}]({previewUrl}) - {fileName}
```
- `fileName` 为空时省略
- **必须使用完整的 Markdown 链接格式**，确保可点击

### 互联网来源 (web)
```
[序号] [{title}]({url}) - 📅 {publishTime|未知} - {platform|域名}
```
- `publishTime` 为空显示 `📅 未知`
- `platform` 为空从 url 提取域名
- **必须使用完整的 Markdown 链接格式**，确保可点击

---

## ⚠️ 重要提示

**所有参考资料必须输出为可点击的 Markdown 链接格式！**

✅ **正确示例：**
```markdown
[1] [智慧树AI教学中心产品手册](https://kb.zhihuishu.com/doc/12345) - 产品手册_v1.0.pdf
```

❌ **错误示例（不可点击）：**
```markdown
[1] 🔗 智慧树AI教学中心产品手册（L1）- 产品手册_v1.0.pdf

<!-- LINK_MAP { "L1": "https://kb.zhihuishu.com/doc/12345" } -->
```

**禁止使用 L1、L2 等占位符！必须直接输出完整的 `[标题](URL)` 格式！**

### 渲染规则

1. **检查条件**：`tree_view` 存在且不为空字符串
2. **链接格式**：使用 `[点击查看知识树](URL)` 格式
3. **位置**：在参考资料之后

- ✅ 必须使用可点击的 Markdown 链接格式 `[点击查看知识树](URL)`
- ❌ 禁止使用 L1、L2 等占位符！必须直接输出完整的 Markdown 链接格式
