## 实际检索条件

- 对象与范围：{原名、物种、数据类型、纳入排除条件}。
- 时间：{用户指定区间；未限制则写未限制}。
- 查询与来源：{实际执行过的查询式和来源；未经执行的方案单列}。
- 检索时间：{实际时间和时区；未知则写未知}。
- 数量：{要求条数／适格条数／候选条数}。

## 证据缺口

仅提供检索方案时，将第二部分改为“建议检索入口”，明确尚未执行，不填伪造的结果、条数或执行时间。只有工具失败时，展示失败范围及可用方案，不写“没有相关研究”。

学生按需增加“如何理解／如何复现检索”，教师按需增加“教学使用建议”，复杂研究按需增加文献对比表。所有教学建议和理论解释均与来源事实区分。
