# Helix｜分子生物学学术检索专家

## 定位

面向学生与教师，支持分子生物学文献，以及核酸、基因组、表达、蛋白结构、功能通路、遗传变异、疾病关联、药物酶学、非编码 RNA、微生物病毒和物种分类检索。默认交付简明答案、证据表、原始链接、实际检索条件和证据缺口。师生适用相同证据要求，解释深度随学习、教学选材或初步科研任务调整。

这是本地专家配置与技能包交付，不代表已经在 PDS 创建、挂载或完成真实检索。没有自动写入线上配置或发送测试消息。

## 文件怎么用

1. 平台使用标准模板时，将 [Agent.md](Agent.md) 作为模板，按 [PDS字段.md](PDS字段.md) 填入对应字段，保持变量名不变。
2. 平台提供完整自定义提示词编辑器时，可直接使用 [Agent-完整配置.md](Agent-完整配置.md)。不要同时叠加完整配置与同样内容的字段，避免重复注入。
3. [PDS字段.json](PDS字段.json) 是字段内容的唯一权威源；另两份是供复制的展开视图。修改后需同步刷新并运行 tests/test_package.py 检查一致性。
4. 分别导入生信适配包与 deep-search 兼容包；external-knowledge-search 复用现有平台技能。外层专家交付 ZIP 用于归档，不可作为单个 Skill 上传。
5. 上线前核对线上实际名称、版本、角色可用性及问答工具映射，再按下方清单联调。平台最终保存属于线上变更，需按项目约定另行确认。

## 开场白

你好，我是 Helix，可以帮助学生和教师检索分子生物学文献，以及基因组、表达、蛋白结构、功能通路、遗传变异、药物靶点、非编码 RNA、微生物病毒和分类数据。你可以直接告诉我研究问题，或提供基因名、物种、论文标题或数据库编号。我会给出相关证据、原始来源链接和检索条件，并说明哪些信息还需要核实。

## 推荐问题

- 查找人类 BRCA1 的蛋白功能与实验结构，区分实验结果和预测模型。
- 我想了解拟南芥某基因与耐盐性的关系，请先帮我确定检索条件。
- 查找近五年与 CRISPR 基因调控有关的 5 篇原始研究，列出主要证据和局限。
- 帮我查找与指定处理条件有关的小鼠 RNA-seq 公开数据集，比较其样本信息。
- 我是教师，想为“基因表达调控”选几篇适合课堂讨论的文献，请注明研究类型和难度。
- 只依据我有权限访问的指定课程知识库解释这一概念，不联网。

“某基因”“指定条件”等输入缺少关键对象时，专家会通过真实交互追问；不会擅自选定。

## 适配说明

原 bioinfo-db-search.md 混合了专家身份与领域技能定义，并引用缺失的 references/db-quick-reference.md、references/db-url-patterns.md、templates/search-report.md。新副本将身份编排放入 Agent，将领域规则放入可独立校验的 Skill，补齐内部资料。0.2.0 已完整保留原稿的 47 个数据库／资源入口，并补充 NCBI Gene；快速路由只用于选出相关入口，不删减完整目录。取消“具备 WebFetch 即可自动查询全部数据库”的假定，实际搜索依赖平台已有能力。本版不提供专用数据库 API 或自动生信计算。

原 deep-search 明确在检索完成后停止并要求另行调用技能，与本次自动整理证据的需求冲突。兼容副本将“停止”限定于检索子流程，允许主专家继续执行已请求的专业核验；同时要求所有初次、新增与重检保留 action_list，统一问答工具映射并修复一个相对文档链接。保留原目录及其 ZIP；复制的 Python 脚本仅清理尾随空白，运行逻辑不变，不代表脚本问题已修复。

## 本地源码核查出的运行风险

以下来自用户提供的文件，不是已证实的线上故障；需使用实际发布版本联调：

- external-knowledge-search 的 SKILL.md 强制每轮获取可用知识库，即使其脚本支持 external_only，也不能据此绕过该前置条件。
- 其 router.py 的 _run_script 会在 stdout 打印子命令，可能破坏单 JSON 输出；parallel 分支将各结果包传给合并函数，结果字段层级有丢失内容的风险。不要只看 success=true，必须核对实际正文、链接及错误状态。
- 其 deep_only 的说明与实际参数传递存在差异，不能保证“不联网”；本配置暂不使用该策略。
- deep-search 在模块载入阶段读取运行时上下文并获取知识库。公开联网检索也不能据 action_list=["internet"] 就保证无身份上下文可运行。
- 检索服务是否能读取具体数据库记录、返回精确标识与版本、读取全文和锁定单门课程，都需要实测。无法确认时返回候选、部分完成或能力不可用，不伪造精度。

本次只适配专家与技能指令，不修改上述原始检索脚本。检索后端未满足验收项时，该路径保持待联调状态。
