# Polymas V5

Polymas V5 专家智能体与 Skill 开发仓库。用于研究、创建、验证和部署专家与技能。

## 目录

| 路径 | 说明 |
|---|---|
| `AGENTS.md` | 本仓库开发约束 |
| `.agents/skills/building-polymas-experts/` | 工程师制作专家智能体 |
| `Polymas Skill V5参考手册.md` | Skill 结构与调用规范 |
| `docs/` | 能力边界、调研与原子技能目录 |
| `polymas-finance-news-expert/` | 财经新闻课程点评专家 |
| `polymas-student-profile-expert-skills/` | 学生画像与个性化推送 |
| `polymas-teacher-work-calendar/` | 教师日历 |
| `ai翻转/` | 数据法学案例等专家材料 |
