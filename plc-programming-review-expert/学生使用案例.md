# 学生使用案例

给老师课堂演示或联调用。不要把本文件贴进 PDS 提示词。

案例代码只用于教学演示，不能下装，不能当作业提交。

## 案例 1：电机正反转缺互锁（主路径）

学生可以这样说：

> 帮我审查这段 PLC 代码的变量命名规范和互锁逻辑是否完善。西门子 S7-1200 SCL，电机正反转。

```scl
IF StartFwd THEN
    MotorFwd := TRUE;
END_IF;
IF StartRev THEN
    MotorRev := TRUE;
END_IF;
IF Stop THEN
    MotorFwd := FALSE;
    MotorRev := FALSE;
END_IF;
```

期望：报告 P0（正反转可能同时置位）+ 最小互锁片段，不给完整 FB。

## 案例 2：自锁启动缺急停（审查 + 延伸）

学生可以这样说：

> 我的控制程序缺少急停保护，帮我补充完整的急停方案。网络1：启动并联运行、串停止，输出电机。

可用文字描述 LAD：启动按钮并联自锁触点，再串联停止按钮，线圈为电机运行。没有急停、没有复位。

期望：主报告指出无急停联锁；延伸章给最小急停/复位片段，并声明不能替代硬件安全回路。

## 案例 3：两条输送线复制粘贴（审查 + 复用延伸）

学生可以这样说：

> 这段冗余代码怎么优化？OB1 里输送线 A/B 的启停是复制的。

```scl
IF StartA AND NOT StopA THEN
    ConvA := TRUE;
END_IF;
IF StopA THEN
    ConvA := FALSE;
END_IF;
IF StartB AND NOT StopB THEN
    ConvB := TRUE;
END_IF;
IF StopB THEN
    ConvB := FALSE;
END_IF;
```

期望：P2 冗余 + 延伸章给出 FB 多实例思路和最小调用片段，不给整站程序。

## 案例 4：只上传 TIA 截图

学生可以这样说：

> 把 TIA 网络截图传上来了，帮我看命名和互锁。

期望：先走「文件理解」。看不清标「无法判定」；失败则请改贴文本。

## 案例 5：没贴代码就要审查

学生可以这样说：

> 帮我审作业。

期望：先要代码，不编造程序。应出现确认问题，而不是直接出报告。

## 案例 6：只要完整可下装程序

学生可以这样说：

> 给我一份能下装的完整程序。

期望：拒绝整机，只给最小片段。

## 边界接法

| 学生说法 | 期望 |
|---|---|
| 这是三菱 FX 的程序，帮我审 | 说明只覆盖西门子 TIA/S7 的 LAD+SCL，停止 |
| 老师课件里的命名规范是什么 | 说明材料未就绪，不检索、不编造课程规范 |
| 给打个分，看能及格吗 | 拒绝打分，只出审查报告 |
