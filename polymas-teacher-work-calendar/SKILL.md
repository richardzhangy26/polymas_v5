## 技能说明

该技能为教师用户提供工作日历查询服务。Agent 可查询教师的教学日程安排，包括课程、会议、作业截止、考试和 AI 提醒，支持按时间范围（今天/明天/本周等）和事件类型进行筛选。

**用户角色**：仅限教师用户使用

| 核心能力 | 输出内容 |
|---------|--------|
| 日程查询 | 按时间范围查询教学日程 |
| 类型筛选 | 按日历/作业/考试/AI提醒分类查询 |
| 时间解析 | 将"今天""明天""本周""下周"等自然语言转换为日期范围 |

---

## 触发条件

当**教师用户**表达以下与工作日历/日程查询相关的意图时触发该技能：

### 1. 查询教学日程
用户希望查看某个时间段的课程、会议、作业截止等安排。

**示例表述**：
- "我明天有什么课"
- "这周有什么安排"
- "下节课在哪个教室"
- "今天有哪些考试"
- "帮我看看本周的作业截止"

### 2. 按类型查询
用户希望只看某一类事件（作业/考试/AI提醒）。

**示例表述**：
- "这周有哪些考试"
- "今天的作业截止提醒"
- "最近的AI提醒"

## 工具清单

### 工具1：get_teaching_schedule.py — 教学日程查询

| 项目 | 说明 |
|------|------|
| **命令** | `python3 scripts/get_teaching_schedule.py [options]` |
| **参数** | `--type`（类型，默认0）、`--start-date`（开始日期，未传默认今天）、`--end-date`（结束日期，未传默认同开始日期）、`--sort-id`（排序ID，可选；默认按日期自动判断：历史日期 -1，今天及未来 1，不得传 0）、`--limit`（数量限制，默认20） |
| **返回** | 教学日程列表 |
| **用途** | 查询教师在指定时间范围内的教学日程安排 |

## 执行流程

**Step 1 [PARSE]：解析时间范围**

将用户的自然语言时间描述转换为具体的 startDate 和 endDate：

| 用户表述 | startDate | endDate |
|---------|-----------|----------|
| 今天 | 今天日期 | 今天日期 |
| 明天 | 明天日期 | 明天日期 |
| 后天 | 后天日期 | 后天日期 |
| 本周 | 本周一日期 | 本周日日期 |
| 下周 | 下周一日期 | 下周日日期 |
| 本月 | 本月1日 | 本月最后一天 |
| 最近/近期 | 不传 startDate/endDate（脚本默认今天，自动使用 sortId = 1 + limit） | — |

日期格式：`yyyy-MM-dd`

---

**Step 2 [PARSE]：解析事件类型**

根据用户意图确定 type 参数：

| 用户意图 | type 值 |
|---------|---------|
| 所有日程/综合安排 | 0（日历） |
| 作业/作业截止 | 1（作业） |
| 考试/测验 | 2（考试） |
| AI 提醒/智能提醒 | 3（AI提醒） |

---

**Step 3 [EXECUTE]：调用查询接口**

根据解析结果调用工具1：

```bash
python3 scripts/get_teaching_schedule.py --type 0 --start-date "2026-07-20" --end-date "2026-07-20"
```

查询"近期"数据时（如"最近有什么安排"）：

```bash
python3 scripts/get_teaching_schedule.py --type 0 --limit 10
```

---

**Step 4 [BUILD]：构造响应**

根据返回数据按时间排序，分组展示日程列表，格式详见 `output_format/teaching_schedule_output_format.md`。

## 约束说明

| # | 约束 |
|---|------|
| 1 | 时间范围必须转换为 `yyyy-MM-dd` 格式 |
| 2 | 用户未指定时间范围时，默认查询"今天" |
| 3 | 用户未指定类型时，默认查询 type=0（日历，包含所有类型） |
| 4 | 查询"近期/最近"时，不传日期参数，脚本默认今天并自动使用 sortId = 1 + limit |
| 5 | sortId 不得传 0（否则查不出数据）；未显式指定时脚本按日期自动判断：历史日期 -1，今天及未来 1 |
| 6 | 日期参数不得为空（后端会报 SQL 错误）；未传时脚本自动填充今天 |
| 7 | 日程按时间正序排列展示 |
| 8 | 空数据不报错，展示"该时间段暂无安排" |

|------|---------|---------|
| 认证令牌获取失败 | 回复"认证令牌获取失败，请稍后重试" | 是 |
| 日程查询失败 | 回复"日程查询失败，请稍后重试" | 是 |

| 时间范围无法解析 | 回复"无法识别时间描述，请明确时间范围（如：今天、明天、本周）" | 是 |
