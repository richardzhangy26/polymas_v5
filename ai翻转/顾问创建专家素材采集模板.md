# 专家创建需求与素材收集表

> **给顾问的话：**请和老师一起填写，直接替换【】中的内容即可。不确定的地方写“待沟通”，不用填写技术方案。
>
> 下方以“数据法学案例专家”为例，其他课程或专业可参照修改。

## 一、这个专家是做什么的？【必填】

- **学校 / 课程：**【例如：XX大学 / 数据法学】
- **专家名称：**【例如：数据法学案例专家】
- **主要使用者：**【学生 / 老师 / 两者都有】
- **一句话说明用途：**【例如：帮助学生学习和讨论案例，帮助老师持续补充案例库】
- **准备放在哪里使用：**【例如：XX课程的 AI 助教中；不清楚可写待沟通】

## 二、希望专家帮忙完成哪些事？【必填】

请按“用户怎么问 → 专家怎么做 → 最后得到什么”填写，先写最重要的 1～3 项。

### 功能 1：【例如：学生案例问答】

- **用户会怎么问：**【请填写一句真实问题】
- **专家应该怎么做：**【例如：找到对应案例，解释相关内容，最后提出一道思考题】
- **最后得到什么：**【例如：案例讲解＋相关法条＋思考题】

**参考示例：**

> 学生：@案例专家 请问虚假招聘侵害个人信息案涉及哪些法律条文？
>
> 专家：根据案例材料解释涉及的法条及其与案件的关系，再追问：“如果招聘方事先取得了应聘者同意，是否就可以随意使用这些信息？为什么？”

### 功能 2：【例如：老师补充案例库】

- **用户会怎么说：**【例如：上传案例文件，要求加入“就业与招聘”场景】
- **专家应该怎么做：**【例如：读取文件，拆分案例，判断分类，展示新增或修改内容，等老师确认后更新】
- **最后得到什么：**【例如：更新后的案例库 HTML，且专家之后能够检索和回答新增案例】

**参考示例：**

> 老师：@案例专家 请把上传文件中的案例补充到就业场景。
>
> 专家：整理案例并展示更新预览，请老师确认；确认后更新案例库，返回 HTML 文件或链接，并说明知识库是否同步成功。

### 其他功能【选填】

【例如：比较两个案例、推荐延伸阅读、按教学主题查找案例】

## 三、请提供哪些材料？【必填】

请随本表一起提供以下材料；没有的标注“暂无”。

- [ ] **课程简介：**课程名称、主要教学内容、学生年级或学习基础；一小段文字即可。
- [ ] **现有内容材料：**案例、教材章节、讲义、课件等。优先提供可复制文字的 Word、PDF、Excel。
- [ ] **内容目录或索引：**列出材料名称及所属分类。已有表格可直接提供，不用重新整理。
- [ ] **希望专家回答的真实问题：**至少 3 个学生问题；有教师维护功能时，再提供 1 个老师操作示例。
- [ ] **期望效果参考：**选 1 个问题，提供老师认可的回答或要点；不用每个问题都写标准答案。

**材料情况：**

- 共【】个案例 / 条目，分为【】类。
- 一个文件中包含【一个 / 多个】案例或条目。
- 材料位置或附件名称：【】。
- 材料是否允许用于专家知识库，以及是否允许向学生展示：【允许 / 部分允许，注明范围 / 待确认】。

> 不要求提前把每个案例拆成单独文件，但请尽量保留案例标题和分类。扫描件请保证清晰；缺失内容标“未提供”，不要为了填满而补写。

## 四、内容怎么分类、怎么展示？【案例库类专家必填】

### 1. 分类方式

【列出场景或分类名称；例如：就业与招聘、智能汽车、医疗健康、金融征信、儿童个人信息保护。没有现成分类可写“请协助建议，老师确认”。】

### 2. 每个案例希望展示的内容

默认按以下五部分整理，可按课程需要增减：

1. **基本案情：**发生了什么，涉及哪些主体。
2. **争议焦点：**主要争议或需要讨论的问题。
3. **涉及法律条文：**材料提到的法律名称、条款及相关说明。
4. **裁判或处理结果：**法院判决、行政处理或其他结果；尚无结果则明确标注。
5. **法律问题分析：**老师认可的分析、教学重点或讨论角度。

请尽量附上案例的**来源、时间、链接或文件名**。不是法院案件的材料，不必填写“法院判决”。

**展示形式：**【默认：HTML 首页按场景分类 → 点击场景查看案例列表 → 点击案例查看详情】

## 五、哪些地方需要老师确认？【必填】

没有特殊要求时，可直接采用以下默认规则：

- **未说明分类：**专家推荐分类或列出选项，由老师确认。
- **遇到重复案例：**展示差异，让老师决定合并、修改或保留为不同案例。
- **缺少案情、法条或处理结果：**标注缺失，不编造。
- **新增、修改、删除或发布：**先展示预览，老师确认后执行；学生只能查询，不能修改。
- **回答超出材料：**说明哪些来自材料、哪些是拓展分析；无法确认时如实说明。

**其他限制：**【例如：不展示未脱敏个人信息、不公开内部教学材料、不直接给出作业答案】。

**日常内容确认人：**【老师称呼或岗位即可，不需要账号密码】。
