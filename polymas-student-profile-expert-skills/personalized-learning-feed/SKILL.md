# Personalized Learning Feed

## 技能说明

本技能负责“读取已确认画像 → 检索可信内容 → 过滤与排序 → 去重 → 生成简报 → 必要时单学生投递”。它不创建或管理定时任务；上层专家使用内置定时能力触发本技能。

## 触发条件 / 不触发条件

### 触发条件

- 定时任务要求为当前学生生成一次个性化简报。
- 学生主动要求推荐应用案例、学习资源、论文或学术活动。
- 上层专家提供了有效的学生画像路径或已确认画像内容。

### 不触发条件

- 学生尚未完成画像，或画像没有明确的兴趣、薄弱模块和发展方向。
- 用户只想填写或修改问卷。
- 请求要求向班级、群组或无法唯一识别的多个会话发送个性化画像内容。

## 项目结构

- `references/data-contract.md`：输入画像、候选内容、评分和推送历史契约。
- `output_format/digest.md`：个性化简报展示格式。
- `SKILL.md`：检索、过滤、排序、投递和审计流程。

## 执行流程

1. **[DETERMINE] 读取当前学生画像**
   - 从可信运行时上下文读取 `schoolId`、`userId`。
   - 读取 `student_profiles/{schoolId}/{userId}/profile.json`；身份键必须与运行时一致。
   - 画像不存在、未确认或字段不足时停止，交回 `student-survey-profile` 补齐。

2. **[BUILD] 构造脱敏检索计划**
   - 只使用 `recommendation_profile` 和内容偏好，生成不超过 3 条检索查询。
   - 查询分别覆盖：兴趣方向的先进应用、薄弱模块的学习资源、未来方向的论文或学术机会。
   - 检索参数不得包含姓名、学号、`schoolId`、`userId` 或完整画像。

3. **[CALL] 获取候选内容**
   - 优先调用 `search-router` 作为统一入口。
   - 结果不足、缺少外部时效信息时调用 `web-domain-search` 补充。
   - 只有用户明确要求深度报告时才调用 `deep-agent-research`；普通定时简报保持轻量。

4. **[FILTER] 可信度与时效过滤**
   - 保留来源 URL、来源机构、发布日期或活动日期。
   - 优先级：官方机构/高校/学会/出版社 > 权威媒体 > 其他公开网页。
   - 学术会议必须仍在未来；论文需标注“同行评审”或“预印本”；无法验证的候选不进入简报。

5. **[FILTER] 匹配排序与去重**
   - 按兴趣匹配 40%、薄弱模块帮助度 30%、发展方向 20%、新鲜度 10% 排序。
   - 读取 `push_history.jsonl`，按规范化 URL 优先、标题与日期组合次之进行去重。
   - 同一学生 30 天内不重复推送同一内容；最终保留 3—5 条。

6. **[BUILD] 生成个性化简报**
   - 按 `output_format/digest.md` 输出，每条包含类型、标题、摘要、推荐理由、来源、日期和下一步行动。
   - 推荐理由必须明确关联画像字段，避免泛化为“你可能感兴趣”。

7. **[CALL] 单学生投递**
   - 交互式调用时直接返回简报，由学生当前会话展示。
   - 定时调用时使用内置 `channel_message`：先查询会话，再选择与当前 `userId` 唯一对应的学生会话，最后发送一次。
   - 会话无法唯一确定时停止投递并返回可审计错误，不改投其他会话或群组。

8. **[BUILD] 记录结果**
   - 只有 `channel_message` 返回成功后，才向 `push_history.jsonl` 追加内容键、画像版本、发送时间和投递结果。
   - 完成标准：简报有真实来源；投递结果可验证；历史记录与实际发送一致。

## 暂停确认规则

- 学生在当前会话主动索取推荐时，无需额外确认即可展示结果。
- 定时任务已包含学生对该频率和渠道的明确授权时，可直接执行本次投递。
- 缺少有效订阅授权、目标会话不唯一或学生已暂停订阅时，停止投递并交回上层专家处理。

## 执行流程强制约束

- 本技能只生成和投递内容，不创建、修改、暂停或删除定时任务。
- 个性化内容只进入当前学生的唯一会话；没有唯一目标时以失败结束。
- 搜索结果必须保留来源并经过日期校验；不得虚构案例、论文、会议、链接或截止日期。
- 推送历史以成功投递为写入条件；失败重试不得制造“已发送”记录。
- 外部检索只接收脱敏主题词；技术身份和完整画像始终保留在内部工作区。
- 对检索不足、发送失败和部分完成使用真实状态，不用生成文本冒充工具成功。
